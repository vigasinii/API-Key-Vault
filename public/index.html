Features

Everything you need,
nothing you don't.

🔑
Masked by default

Keys always shown as ••••. One click to copy the real value — never exposed in plain text unless you explicitly reveal it.

⏰
Expiry tracking

Set expiry dates on any key. Expired keys surface automatically in the Expiring view with visual warning badges.

🏷
Tags & search

Tag keys with comma-separated labels. Instant search across names, services, tags, and notes.

📊
Usage tracking

Every copy or reveal stamps last_used. See which keys are active daily and which are gathering dust.

🗄️
SQLite backend

All data in Turso — managed SQLite with a generous free tier. Zero ops, instant queries, schema bootstraps itself.

🚀
Deploy in 5 min

Vercel + Turso = two commands. No Dockerfile, no config hell. Push to git and you're live on a global CDN.

How it works

Three steps to your
own private vault.

01
Clone & install

Download the project, run npm install. No framework, no bundler — clean HTML, CSS, and serverless functions.

npm install
02
Create a Turso DB

One CLI command creates your database. Paste the URL and token into .env.local — schema bootstraps on first request.

turso db create vault
03
vercel --prod

Add env vars to Vercel, deploy once. Your vault is live on a global CDN with HTTPS and zero infra to manage.

vercel --prod
